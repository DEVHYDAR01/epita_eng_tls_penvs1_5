# TP2 Engineering Tools — NASA APOD CLI

**Author:** Aliyu Hydar Ahmad (`aliyu.ahmad`) — Group 5

CLI that fetches NASA's Astronomy Picture of the Day and renders the live data
with `rich`.

## Usage

```bash
cp .env.template .env   # then set your real NASA_API_KEY in .env
uv sync
uv run epita-aliyu-ahmad-cli
```
